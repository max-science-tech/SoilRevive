## 🌱 SoilRevive MVP Architecture

### User Flow

1. User selects a plant
2. User answers symptom questions
3. Diagnosis engine checks the rules
4. Soil Health Score is calculated
5. Emergency remedies are suggested
6. Progress is tracked over time

---

### System Components

#### Input Layer

* Plant type
* Soil moisture
* Leaf condition
* Fungal presence
* Growth condition

#### Processing Layer

* Symptom analysis
* Rule-based diagnosis engine
* Soil Health Score calculation

#### Output Layer

* Probable cause
* Confidence level
* Home remedy suggestions
* Recovery recommendations

---

### Example Workflow

**Input**

* Plant: Curry Leaf
* Soil: Wet
* Leaves: Yellow
* Fungus: Present

**Processing**

* Diagnosis Rule → Overwatering
* Score Calculation → 43/100

**Output**

* Possible Cause: Overwatering
* Confidence: High
* Action:

  * Stop watering for 2–3 days
  * Improve airflow
  * Remove fungal growth
  * Check drainage holes
